# 日高オーダー

やきとり日高での注文を、つまみの量と食べたいものから提案するスマホ向けの静的Webアプリです。つまみの量は「軽め1品」「普通2品」から選び、小皿・つまみだけの品数を決めます。串はししとう1本を含む5本固定、締めは自動追加しません。一品料理は直近3回来店をなるべく避けた「今日の一品候補」を表示し、候補欄内のスイッチを入れた場合だけ別枠で追加します。3,000円を目安にしながら固定条件を優先します。ブラウザからそのまま使えるほか、PWAとしてホーム画面へインストールできます。

## 使い方

1. `index.html` をブラウザで開く。
2. 条件を選び、「この条件で注文を考える」を押す。
3. 内容がよければ「この注文を記録」を押す。次回以降は、最近食べた料理を内部で自動的に避けます。

基本画面の「すべての履歴を見る」から、過去の注文を日付ごとに確認できます。アプリで記録した履歴には、商品ごとの価格と当時の合計金額も表示されます。

注文履歴は、来店ID・注文履歴ID・店舗IDに加え、商品ごとのメニューID・注文順・数量・注文時価格・おすすめ／手動追加の区別を保存します。メニュー価格を後から変更しても、過去の注文時価格は変わりません。さらに、注文案を作ったときの目安予算・つまみの量・串本数・食べたいもの・最初の飲み物・ししとう必須・締め・最近の重複回避・焼酎キープ利用も履歴内へ保存します。既存データとの互換性のため、保存項目名の一部は従来形式を維持します。1軒目／2軒目、2軒目予定、魚介・肉・旬の明示希望、滞在時間、その他の希望は将来の画面追加に備えた空欄として保持します。従来形式の履歴は、起動時やバックアップ復元時に不明な条件を推測せず、新しい形式へ自動変換されます。

注文案を作ると、その内容は「未記録の注文」として端末内へ自動保存されます。記録前は「この注文を記録」ボタンが画面下に固定され、10分後と次回起動時に確認画面が表示されます。確認画面では、注文を記録する・内容を確認する・今回は記録しない、のいずれかを選べます。未記録の注文は履歴には自動追加されないため、実際に頼まなかった注文が履歴へ入ることはありません。

注文案を作った後に条件から考え直したい場合は、「条件をリセットして最初から」を押します。つまみの量・飲み物・食べたいもの・今日の一品候補の採用状態・未記録の注文案を初期状態へ戻します。メニュー、注文履歴、当日の品切れは削除しません。

画面右上の歯車からメニューを編集できます。管理一覧は「タグ順」と「区分順」を切り替えられ、選んだ並び順を端末内へ保存します。編集画面では、区分を1つ、タグを食材・内容／用途・特徴のグループから複数、スイッチ形式で選べます。外部データで独自タグを取り込んだ場合も「その他の登録済みタグ」として選択できます。提供区分は「通常・季節・期間限定」から選び、季節、任意の提供期間、メモも登録できます。期間外の商品は注文候補から外れますが、メニューと過去履歴には残ります。データはこのブラウザの端末内ストレージに保存されます。
Supabase接続設定はローカルで準備できますが、現在の保存先は引き続き端末内です。データ管理画面の「クラウド接続（確認用）」から、焼酎キープ管理と同じ利用者でログインし、ログイン中のメールアドレスと、対象となるメニュー・来店履歴・店舗設定の件数を読み取り確認できます。メールアドレスは接続状態の表示にだけ使い、端末内のセッションには保存しません。現段階ではクラウドへの追加・変更・削除は行いません。

「全データをバックアップ」では、店舗情報・メニュー・登録済み初期メニュー・注文履歴・設定・当日の品切れ・未記録注文を、保存日時と形式バージョン付きのJSONとして端末へ保存できます。現在の完全バックアップ形式はバージョン6で、従来のバージョン1〜5も復元できます。「全データを復元」では、バックアップ日時と件数を確認してから端末データを上書きします。

既定店舗は `data/stores.json` で管理し、「やきとり日高」に固定店舗ID `hidaka-001` を設定しています。基本メニューCSVと注文履歴にも店舗IDを保存するため、将来ほかの店舗やSupabaseへ拡張してもデータを区別できます。店舗名とID、アプリ版、メニューデータ更新日は、データ管理画面の下部で確認できます。

基本メニューCSVには、並べ替えや削除をしても変わらない `メニューID` を設定しています。現在のメニューをCSVへ保存した場合も、このIDと店舗IDを含めて保存されます。

メニューは「提供中」と「休止中」で管理します。休止中の商品はデータと過去の履歴を残したまま、注文候補・飲み物・食べたいもの・手動追加から除外され、管理画面から再開できます。CSVバックアップでも提供状態を保持します。
焼酎キープの割代（220円）は固定費として予算に含め、注文案の最後に表示されます。
3,000円は上限ではありません。高額品を含めて目安を超えた場合は、商品ごとの選定理由と超過額を表示します。
注文案では、商品ごとの「品切れ」をチェックして再提案できます。品切れはその日のみ端末内に保存され、翌日には自動でリセットされます。「メニューから追加」では、今回の注文に限り候補外の商品を追加できます。手動追加分は提案の予算計算には影響せず、注文合計だけに反映されます。

おすすめ商品ごとの「変更」では、品切れにせず今回だけ別の商品へ置き換えられます。変更理由は任意で選択でき、注文履歴にはAIが提案した元の商品・実際に選んだ商品・変更理由を分けて保存します。変更済みの商品と手動追加商品は、注文案を組み直しても残ります。
注文を記録した後は、満足度1〜5・次回の希望・量・金額感・コメントを任意で保存できます。「後で入力」を選んだ場合も、過去の注文履歴から感想を入力・編集できます。
「食べたいもの（任意）」には、現在のメニューで登録数が多い食材系タグの上位5種類が自動で表示されます。何も選ばなくても注文案を作成できます。
現在のメニューを初期メニューとして登録すると、「初期データに戻す」でもその内容に戻せます。

基本メニューは `data/hidaka-menu.csv` から読み込みます。歯車メニューの「現在のメニューをバックアップ」から編集済みメニューをCSVとして端末へ保存でき、「基本メニューCSVを保存」から配布時の基本CSVも保存できます。

## Supabase接続の準備

ローカルでは `config.example.json` を見本に `config.local.json` を作成します。`config.local.json` はGitHub対象外で、公開用接続キーと店舗IDをローカルだけに保持します。焼酎キープ管理と同じメールリンク方式を使い、パスワード入力はありません。別ブラウザへログイン状態が分かれるのを避けるため、メールのログインリンクを日高オーダー内へ貼り付けて認証できます。貼り付けたリンクは保存せず、認証後は一般的なログイン継続用トークンだけをこの端末に保存します。現在の処理は本人のデータ件数を読み取る確認までで、クラウドへの追加・変更・削除は行いません。設定ファイルがない公開版でも端末内保存のまま通常動作します。

Supabase Authの許可済み戻り先には、ローカル確認用 `http://127.0.0.1:8135/**` と公開版 `https://haraken59-bot.github.io/hidaka-order/**` を登録しています。

## スマホへのインストール

Android版Chromeで公開URLを開き、画面右上に表示される「インストール」を押します。表示されない場合は、Chromeのメニュー（︙）から「アプリをインストール」または「ホーム画面に追加」を選びます。

初回はChromeがインストール可能と判定するまで少し時間がかかる場合があります。ページを一度操作し、30秒ほど開いたままにしてから再読み込みしてください。

## 外部データの取り込み

歯車メニューの「外部データを取り込む」から CSV または JSON を選択します。

メニュー CSV の列:

```csv
メニューID,店舗ID,料理名,価格,分類,タグ,実額,提供状態,提供区分,季節,提供開始日,提供終了日,メモ,最終更新日
base-001,hidaka-001,ししとう串,180,skewer,野菜|軽め,false,提供中,通常,,,,,
base-002,hidaka-001,季節の魚料理,680,small,魚介,true,提供中,季節,春,2027-03-01,2027-05-31,,2027-03-01T10:00:00.000Z
```

履歴 CSV の列:

```csv
店舗ID,日付,注文
hidaka-001,2026-08-01,ハイボール|酢モツ|ししとう串|手羽先
```

分類は `drink` / `small` / `skewer` / `main` / `finish` を使えます（日本語の「お酒」「小皿」「串」「一品」「締め」も可。従来の「主菜」も取り込めます）。タグは `|` 区切りで、「豚」「鶏」「魚介」「野菜」「辛いもの」「軽め」などを指定します。基本CSVのタグは日本語で統一し、従来の英語タグも取り込み時に日本語へ変換されます。提供区分は「通常・季節・期間限定」、季節は「春・夏・秋・冬」を指定できます。開始日・終了日は任意です。

JSON では、次のようにメニューと履歴をまとめて取り込むこともできます。

```json
{
  "menu": [{"storeId":"hidaka-001", "name":"ししとう串", "price":180, "category":"skewer", "tags":["野菜", "軽め"]}],
  "history": [{"storeId":"hidaka-001", "date":"2026-08-01", "items":[{"name":"ししとう串"}]}]
}
```

価格は初期値・取り込み値ともに確認用の例です。来店する店舗の実際のメニューに合わせて更新してください。
