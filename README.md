# 日高オーダー

やきとり日高での注文を、空腹度・気分から提案するスマホ向けの静的Webアプリです。3,000円を目安にしながら、指定した串本数などの条件を優先します。ブラウザからそのまま使えるほか、PWAとしてホーム画面へインストールできます。

## 使い方

1. `index.html` をブラウザで開く。
2. 条件を選び、「この条件で注文を考える」を押す。
3. 内容がよければ「この注文を記録」を押す。次回以降は、最近食べた料理を内部で自動的に避けます。

基本画面の「すべての履歴を見る」から、過去の注文を日付ごとに確認できます。アプリで記録した履歴には、商品ごとの価格と当時の合計金額も表示されます。

注文案を作ると、その内容は「未記録の注文」として端末内へ自動保存されます。記録前は「この注文を記録」ボタンが画面下に固定され、10分後と次回起動時に確認画面が表示されます。確認画面では、注文を記録する・内容を確認する・今回は記録しない、のいずれかを選べます。未記録の注文は履歴には自動追加されないため、実際に頼まなかった注文が履歴へ入ることはありません。

画面右上の歯車からメニューを編集できます。データはこのブラウザの端末内ストレージに保存されます。
焼酎キープの割代（220円）は固定費として予算に含め、注文案の最後に表示されます。
3,000円は上限ではありません。高額品を含めて目安を超えた場合は、商品ごとの選定理由と超過額を表示します。
注文案では、商品ごとの「品切れ」をチェックして再提案できます。品切れはその日のみ端末内に保存され、翌日には自動でリセットされます。「メニューから追加」では、今回の注文に限り候補外の商品を追加できます。手動追加分は提案の予算計算には影響せず、注文合計だけに反映されます。
「今日の気分」には、現在のメニューで登録数が多い食材系タグの上位5種類が自動で表示されます。
現在のメニューを初期メニューとして登録すると、「初期データに戻す」でもその内容に戻せます。

基本メニューは `data/hidaka-menu.csv` から読み込みます。歯車メニューの「現在のメニューをバックアップ」から編集済みメニューをCSVとして端末へ保存でき、「基本メニューCSVを保存」から配布時の基本CSVも保存できます。

## スマホへのインストール

Android版Chromeで公開URLを開き、画面右上に表示される「インストール」を押します。表示されない場合は、Chromeのメニュー（︙）から「アプリをインストール」または「ホーム画面に追加」を選びます。

初回はChromeがインストール可能と判定するまで少し時間がかかる場合があります。ページを一度操作し、30秒ほど開いたままにしてから再読み込みしてください。

## 外部データの取り込み

歯車メニューの「外部データを取り込む」から CSV または JSON を選択します。

メニュー CSV の列:

```csv
料理名,価格,分類,タグ,実額
ししとう串,180,skewer,野菜|軽め,false
ゴマサバ,680,small,魚介,true
```

履歴 CSV の列:

```csv
日付,注文
2026-08-01,ハイボール|酢モツ|ししとう串|手羽先
```

分類は `drink` / `small` / `skewer` / `main` / `finish` を使えます（日本語の「お酒」「小皿」「串」「一品」「締め」も可。従来の「主菜」も取り込めます）。タグは `|` 区切りで、「豚」「鶏」「魚介」「野菜」「辛いもの」「軽め」などを指定します。英語タグも取り込み時に日本語へ変換されます。

JSON では、次のようにメニューと履歴をまとめて取り込むこともできます。

```json
{
  "menu": [{"name":"ししとう串", "price":180, "category":"skewer", "tags":["野菜", "軽め"]}],
  "history": [{"date":"2026-08-01", "items":[{"name":"ししとう串"}]}]
}
```

価格は初期値・取り込み値ともに確認用の例です。来店する店舗の実際のメニューに合わせて更新してください。
